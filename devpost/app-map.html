RefundCurve · Project guide

From policy text to a clearer cancellation decision.

RefundCurve extracts hotel cancellation deadlines, checks each result against the quoted policy, then calculates a potential refund locally and shows how it changes over time.

Code snapshot: a2172be92733b22c032afc917df562bea4ece267. This map is a snapshot and may drift as the code changes.

One action through the app

A traveler submits a policy once. The server checks the model's evidence; the browser handles the financial calculation and timeline movement.

OpenAI receives the pasted policy text and property time zone for the requested analysis. The booking amount and currency remain in the browser. Unsupported or conflicting policy details block the live estimate instead of being guessed.

A 3-stop code route

Reference route · not toured interactively. Open these locations in the editor to follow the same flow as the diagram.

  1. Start where the traveler acts.

    src/components/booking-form.tsx collects policy and booking input. src/components/policy-workspace.tsx keeps the workflow, sample path, and live result together.

  2. Follow the server's evidence gate.

    src/app/api/analyze/route.ts calls the provider through createAnalyzeHandler. supportedRuleEvidenceIssue cross-checks the model's values against the source quote.

  3. Trace a verified rule to its displayed result.

    resolveRules and evaluatePolicy apply property-local time boundaries; calculatePenalty and calculateRefund do decimal arithmetic. TimelineChart and PolicyEvidence show the result and its source.

To change this, start here

  • Support another policy phraseStart with prompt.ts, then update the exact evidence rules in validate-analysis.ts and its tests.
  • Change how a deadline affects moneyStart with evaluate-policy.ts and money.ts; preserve exact-boundary and rounding checks.
  • Adjust the sample bookingEdit the fictional fixture in tokyo-policy.ts; it uses the same deterministic calculation path.
  • Change the visual treatmentStart with globals.css and the relevant component. Keep the native range input keyboard-accessible.

A practice to reuse

Make the evidence requirement testable before an AI output can drive a consequential result. RefundCurve's approved prd.md · Analysis and Rule Evidence says each supported rule needs a source excerpt. tests/unit/validate-analysis.test.ts checks matching and mismatching dates, times, percentages, and policy scope. In another AI-assisted project, define what an answer must prove, then test both the evidence that qualifies and the evidence that should leave the result unresolved.

Run the app again

The fictional Tokyo example works without an API key. Live analysis needs a server-side OPENAI_API_KEY; do not put the key in client code or commit .env.local.

npm install
cp .env.example .env.local
npm run dev

Then open http://localhost:3000. The code map is a local reference file at devpost/app-map.html; reopen it from the project folder or the editor.
